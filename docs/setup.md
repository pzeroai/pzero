# Setup Guide

## Prerequisites

- **[Bun](https://bun.sh)** v1.0+
- **ClickHouse** (local or remote, HTTP interface enabled)
- **An LLM API key**
- **Polygon RPC URL** (for Polymarket blockchain indexers)

## Installation

```bash
git clone https://github.com/pzeroai/pzero.git
cd p0
bun install
cp .env.example .env
```

## Configuration

Edit `.env`:

| Variable              | Required | Default                  | Description |
|-----------------------|----------|--------------------------|-------------|
| `LLM_API_KEY`         | Yes      | —                        | API key for LLM provider |
| `LLM_BASE_URL`        | No       | `https://api.openai.com/v1` | OpenAI-compatible endpoint |
| `LLM_MODEL`           | No       | `gpt-4o`                 | Model identifier |
| `CLICKHOUSE_URL`      | Yes      | `http://localhost:8123`  | ClickHouse HTTP endpoint |
| `CLICKHOUSE_USER`     | No       | `default`                | ClickHouse user |
| `CLICKHOUSE_PASSWORD` | No       | empty                    | ClickHouse password |
| `CLICKHOUSE_DATABASE` | No       | `default`                | ClickHouse database |
| `POLYGON_RPC`         | Yes*     | —                        | Required for Polymarket trades/blocks indexers |
| `DATA_DIR`            | No       | `./data`                 | Cursor/checkpoint file directory for indexers |

\* `POLYGON_RPC` is not required if you only run the API without blockchain ingestion jobs.

## Migrate Existing Parquet Data

If you already have parquet files under `DATA_DIR` in the legacy structure (`kalshi/*`, `polymarket/*`), load them into ClickHouse with:

```bash
bun run migrate-parquet
```

Useful flags:

```bash
bun run migrate-parquet -- --truncate          # clear destination tables first
bun run migrate-parquet -- --continue-on-error # keep loading other files on failures
```

## Running

### Development

```bash
bun run dev          # API (3001) + web (5173)
bun run dev:api      # API only
bun run dev:web      # Web only
```

### Indexing Jobs

```bash
bun run index                 # list available indexers
bun run index kalshi_markets
bun run index kalshi_trades
bun run index polymarket_markets
bun run index polymarket_trades
bun run index polymarket_blocks
bun run index polymarket_fpmm_trades
```

### Scheduler

```bash
bun run scheduler
```

## Notes

- API startup creates/replaces analytics views in ClickHouse.
- Queries are generated by the LLM as ClickHouse SQL.
- There is no DuckDB/parquet runtime dependency in the API query path.
